# VHS Filter

Apply VHS video tape filter to your image. https://hazama.cc/vhs_filter

Written in pure TypeScript. All processing runs locally.
This is a Vue 3 with Bootstrap 2.3.2 for that authentic 201x retro look. 

## Build

```sh
pnpm install
pnpm dev      # start dev server
pnpm build    # production build into dist/
pnpm preview  # serve the production build
```
